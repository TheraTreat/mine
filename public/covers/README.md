# Book covers

Drop real cover images here and the site picks them up automatically
(the styled placeholders disappear — no code changes needed):

- `therapy-for-all.jpg`
- `the-survivvl-awakening-of-the-dark.jpg`

Requirements: 2:3 aspect ratio, at least 900px wide. `.jpg`, `.png` and
`.webp` are all accepted. Restart `npm run dev` (or re-run `npm run build`)
after adding a file — the check happens at build time.
